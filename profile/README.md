# Big Data · ЖДУ ім. Івана Франка, 2026

Лабораторні роботи з освітньої компоненти «Big Data» для здобувачів другого (магістерського) рівня вищої освіти, ОП «Комп'ютерні науки». Наскрізний проєкт «Монітор закупівель Житомирщини» на відкритих даних ProZorro.

- Кожен здобувач працює в особистому приватному репозиторії `labs-<прізвище>`. Репозиторій відкривається через **Code → Codespaces**: першого разу **Create codespace on main**, надалі наявний Codespace зі списку в тому самому меню; встановлювати програми не потрібно.
- Порядок початку роботи описано в README особистого репозиторію `labs-<прізвище>` (розділ «З чого почати»).
- [Дані курсу](https://github.com/bigdata-16md-2026/bigdata-data): знімок ProZorro (Житомирщина, 2026) і архів ProZorro 2022–2025 (Kaggle, CC0).
