# Big Data · ЖДУ ім. Івана Франка, 2026

Лабораторні роботи з освітньої компоненти «Big Data» для здобувачів другого (магістерського) рівня вищої освіти, ОП «Комп'ютерні науки». Наскрізний проєкт «Ризик-монітор закупівель Житомирщини» на відкритих даних ProZorro.

- Кожен здобувач створює власний приватний репозиторій курсу із шаблону [bigdata-labs](https://github.com/bigdata-16md-2026/bigdata-labs) (шаблон доступний учасникам організації з командою `students`): **Use this template** → **Create a new repository** → власник (**Owner**) `bigdata-16md-2026`, назва `labs-<прізвище латиницею>`, видимість **Private** → **Create repository**.
- У репозиторії відкрити **Code → Codespaces → Create codespace on main** (надалі наявний Codespace зі списку в тому самому меню; встановлювати програми не потрібно) і вписати прізвище, ім'я та призначений індивідуальний сектор (таблиця «прізвище → сектор» міститься в оголошенні курсу) у `config.toml`.
- Порядок початку роботи докладно описано в README шаблону й особистого репозиторію (розділ «З чого почати»).
- [Дані курсу](https://github.com/bigdata-16md-2026/bigdata-data): знімок ProZorro (Житомирщина, 2026) і архів ProZorro 2022–2025 (Kaggle, CC0).
